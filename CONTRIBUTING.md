# Contributing to Womzo

Thank you for your interest in contributing to
this SJB Projects application.

Community contributions, suggestions and constructive
feedback are welcome.

## Ways to contribute

- Report bugs.
- Suggest new features.
- Improve documentation.
- Improve accessibility and usability.
- Add support for additional video providers.
- Improve performance and security.
- Help test the application on different platforms.

## Reporting issues

When reporting a problem, please include:

- The application version.
- Your operating system and browser.
- Your installation method.
- Steps to reproduce the problem.
- Expected and actual behaviour.
- Relevant error messages, where available.

Never include passwords, secret keys, private environment
files or other confidential information.

## Contributing code

1. Fork the repository.
2. Create a branch for your proposed changes.
3. Make focused, relevant changes.
4. Test your changes locally.
5. Update documentation where appropriate.
6. Submit a pull request explaining your changes.

Please keep changes simple, readable and maintainable.

## Development principles

The project aims to remain:

- Lightweight.
- Easy to install.
- Easy to maintain.
- Secure by default.
- Independent of unnecessary external services.
- Accessible across desktop and mobile devices.

Video streams should continue to be played directly
from their providers wherever practical.

Contributions must respect the rights and restrictions
of third-party webcam and media providers.

## Security

Please report suspected security vulnerabilities
privately through the repository's private vulnerability
reporting facility, where available.

Do not publish working exploits or confidential
configuration details in public issues.

## Licensing

By submitting a contribution, you agree to make it
available under the project's AGPL-3.0-only licence.

Contributors retain copyright in their own contributions.

Third-party code must have compatible licensing and
retain its required copyright and licence notices.

## Branding

Please respect the project's branding policy described
in BRANDING.md.

Thank you for helping improve Womzo.
